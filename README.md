## Projects

### [Canadian Restaurant Profitability Benchmark](https://github.com/BenShadabi/canadian-restaurant-profitability-benchmark)
Where does a typical Canadian restaurant make and lose money? Public Statistics Canada and ISED data (2019 to 2025), a what-if on labour, overhead and food waste, SQL queries, and a script that checks every headline number on each push.
[Live dashboard](https://benshadabi.github.io/canadian-restaurant-profitability-benchmark/dashboard.html) · [Compare your own restaurant](https://benshadabi.github.io/canadian-restaurant-profitability-benchmark/calculator.html)

### [Study Map](https://github.com/BenShadabi/study-map-showcase)
A study app I built for my Semester 5 courses: spaced review, exam mode, readiness tracking and a plan tab.
